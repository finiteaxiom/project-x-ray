# A + B + C 界面设计与验收

日期：2026-09-22

## 设计方向

用户选择 Linear 的视觉秩序、GitKraken 的多面板工作台和 React Flow 风格的节点画布。实现沿用现有 Cytoscape、Monaco 和证据工作区，不增加依赖，不修改分析器、Graph IR 或 IPC 契约。

- 石墨背景和分层中性表面，蓝紫色用于操作、导航与选择；绿色、琥珀色与红色保留状态语义。
- 导航使用本地 SVG 图标，提供当前页语义和窄窗口悬停标题。
- 点阵画布、圆角节点、模块与文件配色、路径聚焦与已有图控制保持联动。
- 源码面板使用本地 Monaco 主题，保留准确范围、快照、自动换行与最大化。
- 导入、概览、关系图、文件列表及证据面板统一边框、圆角、间距与键盘焦点。
- 置信度图例同时使用文字与形状，未知和推断边继续使用不同线型。

## 本轮验证

- UI 组件测试 10/10 通过，包括源码导航、答题引用、过期状态和取消。
- UI TypeScript 检查与生产构建通过。构建仍提示 Monaco / 主包体积较大。
- 真实 Electron E2E 通过：导入、查询证据、Git 比较、过期检测、重算与索引更新。
- 真实工作区 E2E 通过：只读索引 ByteAtlas、聚合关系、文件导航、准确源码范围、拖动分栏、关闭/恢复源码、最大化及 106 个符号分页。
- 1920×1080、1280×800 窗口与 1.5 DPR 下无页面横向溢出；图节点在画布边界内。截图人工检查了关系总览、模块、导入和源码分栏。

截图位于 `docs/screenshots/graphite-workbench/`。原截图保留；工作区测试支持 `XRAY_UI_SCREENSHOT_SET` 指定截图子目录。

## 限制

本轮仅交付已接入实际功能的深色界面设计；没有制作安装包，也没有新增远程模型、分析能力或图引擎。复杂图的标签仍随缩放变化，需要使用现有放大/聚焦控制。其他显示缩放与完整跨平台视觉验收未执行。

Git 在工作开始前即将整个项目列为未跟踪，本轮未暂存或提交。

## 第二版：渐进式架构探索（2026-09-22）

本轮完成架构工作区样板：项目总览 → 模块文件 → 关系检查 → 准确源码 → 返回总览。

### 已实现

- 模块节点直接展示当前快照的文件/符号数；目录分组与业务模块的区别仍明确可见。
- 选择模块后查看当前有界范围内的关联模块；聚合关系详情直接出现在总览右栏。
- 选择真实底层关系后先展示关系方向、原因、置信度、文件范围、分析器版本、证据类型和快照。用户点击“定位源码证据”后打开源码，不把静态关系描述为运行时执行。
- 检查面板支持关闭和失败重试。迟到响应被丢弃，证据 ID 或快照不匹配时禁止导航。
- 按仓库、快照与查询上下文，在架构组件会话内记忆最多 40 份图视图（缩放、平移、节点位置与选择）；返回上层恢复视角。拓扑改变时重新布局，不跨快照复用旧事实。
- 层级切换回到图浏览，源码仍可按既有按钮重新显示。符号列表独立滚动，窄分栏使用上下布局，避免列表将图谱滚出视野。
- 修复异步节点首次进入空画布时没有适应视图的问题；大范围源码保留准确选择与行高亮，避免所有行叠加黄色行内装饰。

### 本轮实际验证

- 13/13 UI 测试通过，包含新增证据响应竞态、错误快照、失败重试和异步空图适应回归。
- UI 类型检查与生产构建通过，构建仍有大包体积提示。
- 真实 Electron 核心 E2E 通过：导入、证据、Git 比较、过期检测和重新索引。
- 最终工作区 E2E 通过：ByteAtlas 只读索引、模块关系检查、带证据 ID 的源码导航、分栏拖动、关闭/恢复、最大化、精确范围以及 106 个符号分页。
- 返回总览的缩放和平移与离开前精确一致；1920×1080 与 1280×800 窗口均无页面横向溢出，DPR 为 1.5。
- 截图目录：`docs/screenshots/exploration-v2/`，保留上一版供比较。同一项目与窗口的总览可直接对比；模块验收改为具有跨模块关系的 `src/main`。

### 本轮范围

此次只精做架构探索样板；调用流、变更分析与所有权页面尚未推广新的关系检查工作流。未新增分析能力、依赖或安装包。密集符号图在适应全图时仍需放大或聚焦阅读；视角记忆仅限当前架构会话，不承诺关闭应用后恢复。未验证其他显示缩放。

## 阅读与检索打磨（2026-09-22）

节点列表使用独立组件，支持当前查询范围内的名称/路径搜索、中文类型筛选、稳定排序及每页 40 项分页。更改筛选从第一页开始，结果缩减时页码限制在合法范围；无匹配时提供恢复入口。分页只改变展示，不改变图事实、置信等级或原有查询边界。列表点击通过真实节点回调进入详情或源码。窄面板按容器宽度排列筛选控件，长路径换行。

概览将索引统计、主要工作入口、覆盖摘要与详细规则分层；分析限制可以展开阅读，静态分析不等于运行时路径的提示始终保留。实际验收记录见 FINAL-DESIGN-ACCEPTANCE.md。
