# ADR-0006：可信语言事实与结构化所有权训练

状态：已接受  
日期：2026-09-21

## 背景

旧版图把无法解析的调用目标和真正的外部包都表示为 `external-dependency`，Python 又可能用项目内唯一同名符号补足缺失绑定。旧版所有权模式主要核对引用集合，无法证明调用方向、路径顺序或变量角色。

## 决策

1. Graph IR 升级为 `1.2.0`，显式区分 `external-dependency`、未解析模块、`unresolved-call` 和 `unsupported-semantic`。观察到调用表达式不等于确认目标；未知事实保留原因、证据、分析器版本和 `unknown` 置信度。
2. Python 分析器升级为 `2.0.0`。独立 Python worker 只解析 Base64 输入，不导入或执行目标项目；主进程使用运行时协议校验。模块、类、函数和嵌套函数使用作用域链身份；导入别名、成员别名、相对包和基本 `global/nonlocal` 通过词法绑定解析。赋值遮蔽、动态属性、实例分派、星号/动态导入等无法证明的关系保持 unknown。
3. Ownership Question/Scoring 升级为 `2.0.0`。调用方向、有序调用路径和变量读写题由服务端持有确定性规则，渲染进程只得到题面和候选项。引用必须属于相同项目与快照；重复引用去重。自由文本仅作为本地学习记录，语义明确标记为“未评估”。
4. 每次提交追加保存为本地 `ownership_attempts` 记录；失败题可修正重试。概念状态区分尚未练习、本快照通过、需要复习和分析/源码变化后需要重新验证。旧 mastery 数据兼容读取为 `legacy`，不伪造成新评分体系下的通过。
5. 题目只从 verified 事实生成。推断或未知关系可以说明限制，但不能成为无条件正确答案。没有足够事实时不出题。

## 兼容与迁移

- SQLite 迁移版本 7 新增追加式训练尝试表并保留旧表。
- 旧 Graph IR 快照仍可作为历史证据读取，但不会静默升级其事实语义；要获得 `1.2.0` 分类和 Python `2.0.0` 绑定必须重新索引。
- 分析器版本、Graph IR 版本和配置身份继续参与 snapshotId，旧题和旧掌握不会自动转移到新快照。

## 保守边界

本决策不声称具备 Python 运行时分派、类型推导、描述器/装饰器语义、猴子补丁或框架依赖注入解析。静态 verified 调用只证明源码绑定和调用表达式，不证明运行时一定执行或业务职责已经理解。
