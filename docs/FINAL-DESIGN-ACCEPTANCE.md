# 完整工作台设计验收

日期：2026-09-22

## 交付范围

六个页面统一使用石墨表面、蓝紫操作色、较高对比度的正文与次级文字，以及固定的已验证/推断/未知语义色。设计变量集中在 apps/ui/src/design-system.css。

- 项目概览增加通往架构、功能追踪和所有权训练的真实操作入口；健康状态中文化，忽略规则与限制可展开查看，静态分析边界始终显示。
- 调用流保留搜索、关系类型和查询主操作；深度、方向和置信筛选收进可展开选项，图和结果可在本面板滚动。
- 图谱增加可搜索的节点列表，支持类型筛选、名称/路径排序、每页 40 项与清除筛选。中文类型、完整名称/路径、选中状态与空结果提示连接真实详情或源码导航。
- 功能解释具备标题、搜索提示、可滚动解释步骤和来源导航。
- Git 双侧比较支持窄窗口单列，长文件名/路径换行。
- 所有权训练与文件列表自适应排列，源码工具栏换行而不挤压标题。
- 全局正文与控件颜色、占位文本、禁用状态、焦点轮廓、图谱配色与源码主题统一。

## 本轮实测

- UI 组件测试：19/19。UI TypeScript 检查和生产构建通过。
- 本轮查询状态改进重跑真实 Electron 核心 E2E 并通过；架构工作区与所有权训练 E2E 在上一轮阅读与检索打磨时通过，本轮未重复运行。架构工作区使用 XRAY_UI_CAPTURE=0，仅关闭截图采集，保留全部功能断言；验证分栏、源码范围、视角恢复和 106 个符号分页。
- 自动视觉检查：41 个场景，1600 个可见文字/占位文字样本；最低实测文字对比度 4.90:1。
- 图谱文字、图边/边框和显式源码语法色：47 组配色检查通过。文字阈值 4.5:1，非文字图形边界阈值 3:1。
- 已检测场景未发现页面横向溢出、未声明的内部横向溢出、可见可操作控件中心被其他元素遮挡或输入控件边界低于阈值。
- 场景包括六页面的真实结果、调用/解释/答题源码面板和超过 120 字符的文件名。测试切换页面会先关闭继承的源码面板，确保正文和源码两种状态分别检查。

## 保证边界

本报告只证明列出的场景和检查通过，不是所有显示器/字体/系统主题下绝无错位的保证，也不是完整 WCAG 无障碍认证。自动检查采用当前 DOM 前景/背景合成与控件中心命中检测，不能替代所有复杂重叠、所有滚动位置及所有悬停状态的人工验收。Monaco 只校验显式语法色配色；画布文字随缩放变化，密集图仍需放大。禁用控件不计入文字对比度采样。

本轮没有生成安装包或修改分析器语义。构建仍提示较大资源包。Git 开始和结束均为全项目未跟踪，未暂存或提交。

## 本次回归中的测试修正

Windows 下架构工作区的 Playwright 截图多次超时；原生捕获尝试后仍有后续截图阻塞，未保留该替代实现。测试新增可选 XRAY_UI_CAPTURE=0 将功能断言与截图采集分离，默认仍截图。39 场景设计审计独立运行并成功生成截图，未关闭视觉检查。所有权测试改为精确定位学习范围标题，避免说明文字造成歧义；符号分页测试显式等待首批异步数据，避免零条误判。

## 查询状态改进

调用查询新增搜索/查询中反馈、无匹配说明、结果起点与数量、参数错误及条件修改提示。新搜索不会保留不存在的旧选项；条件变化禁止旧游标续查；深度/节点预算须为范围内整数且至少选择一类置信度。中文输入法组合输入的 Enter 不触发搜索。新增三项回归覆盖这些状态，视觉审计增加参数错误和条件修改场景。
