# 图查询与真实项目浏览基线

运行 `pnpm benchmark` 可复现。命令在 `.benchmarks/` 生成隔离样例和数据库，结果写入 `docs/benchmarks/latest.json`；不会安装或执行被分析项目的依赖、脚本、测试或构建。

## 样例

- `small-gold`：仓库内混合 TypeScript/Python 金标 fixture。
- `medium-200`：确定性生成的 200 个 TypeScript 源文件，加一个清单文件；入口有 50 路分支。
- `large-800`：确定性生成的 800 个 TypeScript 源文件，加一个清单文件；入口有 50 路分支。
- `p-map`：真实开源 JavaScript 项目，来源 `https://github.com/sindresorhus/p-map.git`，固定提交 `f0c43e358a449584c2045c89d1b9ae3cd5a9f293`，MIT。只克隆、检出和读取。
- `deterministic-60-file-chain`：本地生成并提交的 60 文件多跳 TypeScript 调用链，修改链尾后测量双侧捕获、完整分析、影响传播、响应大小和取消。

## 2026-09-20 实测

环境：Windows x64，Node 24.17.0，Intel Family 6 Model 183，24 逻辑处理器，16160 MiB 内存。冷索引各 1 次；重开、搜索、3-hop 各 3 次。不报告 P95。

| 样例 | 文件/节点/边 | 冷索引 | 重开 3 次 | 搜索 3 次 | 3-hop 3 次 | 响应 |
| --- | ---: | ---: | --- | --- | --- | ---: |
| small-gold | 3/15/33 | 435.8 ms | 6.74/3.61/3.76 ms | 0.60/0.28/0.22 ms | 1.88/0.93/0.64 ms | 1.8 KiB |
| medium-200 | 201/604/2541 | 501.2 ms | 4.45/4.38/3.87 ms | 0.61/0.37/0.38 ms | 45.99/40.44/40.85 ms | 76.0 KiB |
| large-800 | 801/2404/9141 | 1307.3 ms | 11.60/8.11/7.01 ms | 2.03/1.23/1.22 ms | 143.68/145.55/137.79 ms | 76.0 KiB |
| p-map | 7/184/929 | 279.6 ms | 3.81/3.66/3.21 ms | 0.41/0.21/0.18 ms | 0.81/0.50/0.44 ms | 0.9 KiB |

中、大样例的高分支查询在 10 节点预算处可见截断，分别约 3.6 ms 与 7.7 ms。SQLite 计划确认搜索使用 `idx_nodes_snapshot_kind`，出边查询使用 `idx_edges_source`；排序仍使用临时 B-tree。当前规模下搜索不是瓶颈，因此没有引入 FTS 或新数据库。

同一 Node 进程顺序运行，`peakProcessRssMb` 是进程采样峰值，后续样本受前序堆保留影响；它只能作为资源上界线索。真实 `p-map` 的所选 `pMap` 节点在当前静态调用视图中没有确认出边，结果是“有节点、无调用证据”，不应补写调用故事。

本轮实测瓶颈原先是每次按需查询仍加载完整快照 JSON；改为只验证小型 overview 后，大样例重开从约 40 ms 降到约 3 ms，搜索从约 30–39 ms 降到约 1–2 ms，3-hop 从约 43–57 ms 降到约 9–12 ms。仍未完成独立进程峰值内存、超大真实仓库和硬件矩阵。

同机真实 Electron E2E 的最终一次观测：首个窗口可操作约 748.6 ms，混合 fixture 导入约 896.9 ms，搜索到证据定位约 390.6 ms，Git 比较约 1312.5 ms，3 秒轮询下报告过期识别约 2833.0 ms，比较重算约 4098.3 ms，重新索引约 800.7 ms。Worker 比较取消响应最终一次观测约 2.54 ms。这些都是单次流程时序，不是分位数。Monaco 编辑器与 worker 从本地延迟加载，E2E 没有访问 CDN。

## Git 双侧比较基线

2026-09-20 同机单次测量：61 个索引文件（60 个源码和一个清单）、链尾 1 个修改文件、最多 6 跳/20 路径/5000 工作量。比较总耗时 1132.0 ms，其中捕获阶段开始到左侧分析开始约 908.8 ms，左右分析及传播后完成；返回 4 条有界影响路径，报告 30,534 bytes，并因路径预算显示截断。取消在进入左侧分析时触发，约 0.70 ms 后返回 `AbortError`。

初始实现逐 blob 启动 `git cat-file`，同一测试总耗时约 3580.8 ms、捕获约 3344.7 ms。改为先批量查询大小、再每批最多 64 个对象读取后，总耗时下降约 68%，捕获下降约 73%。这只是同机单次前后对比，不是统计分位数；完整原始数据见 `latest.json`。

最新常规查询数据以 `latest.json` 为准。本轮重跑中 801 文件项目冷索引约 1307.3 ms，搜索约 1.2–2.0 ms，3-hop 约 137.8–145.6 ms；3-hop 时间较旧记录上升，仍需在独立进程中剖析 SQLite 取边与 JSON 反序列化，不能宣称已达到所有大型仓库目标。
